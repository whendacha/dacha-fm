Dacha FM Support

For the beta app, use “Send Beta Feedback” in TestFlight. Include the steps you took and a screenshot. Do not send recovery phrases, private keys, or passwords.

If sign-in was canceled, tap “Sign in with Meteor Wallet” again, select your wallet, and approve the message signature. Signing this message does not transfer funds.

To sync your library, install build 3 or later and enable cloud sync in Settings by confirming your Meteor sign-in. Sign in with the same wallet on another iPhone. You can import your guest library separately. If a conflict appears, choose the version on this device or the version in the cloud; the app does not replace conflicting data automatically. Without an internet connection, changes are saved on your phone and sent when you sync again.

Music streams from the public catalog and requires an internet connection. If a track is unavailable, try another one. You can hide an artist using the track menu.
