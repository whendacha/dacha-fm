Dacha FM Support

For help with Dacha FM, email whendacha@gmail.com. Include the app version, your iPhone model and the steps needed to reproduce the issue. Do not send recovery phrases, private keys, passwords or session tokens. TestFlight users can also use “Send Beta Feedback”.

Report content

To report objectionable content, impersonation or a rights concern, email Dacha FM support with the recording's title, artist, source link and a description of the concern. In the app, open the song menu → Report → Open recording page to find its source link. You can immediately hide the artist using the song menu.

Dacha FM is an independent player for an external music catalog. A report to Dacha FM does not itself remove a recording from the source service; source removal requests may also need to be submitted to its operator. Do not include sensitive personal information in public GitHub discussions.

Sign-in and your library

If sign-in was canceled, tap “Sign in with Meteor Wallet” again, select your wallet, and approve the message signature. Signing this message does not transfer funds.

To sync your library, install build 3 or later and enable cloud sync in Settings by confirming your Meteor sign-in. Sign in with the same wallet on another iPhone. You can import your guest library separately. If a conflict appears, choose the version on this device or the version in the cloud; the app does not replace conflicting data automatically. Without an internet connection, changes are saved on your phone and sent when you sync again.

Music streams from the public catalog and requires an internet connection. If a track is unavailable, try another one. You can hide an artist using the track menu.

For privacy questions or account-data requests, use the same support email. Cloud profiles can be deleted directly in Settings → Delete account.
